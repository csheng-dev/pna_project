## Faster R-CNN 概述

Faster R-CNN 是两阶段目标检测模型，由以下四个主要组件构成：
1. **Backbone（骨干网络）**：特征提取器（如 ResNet50）
2. **FPN（Feature Pyramid Network）**：特征金字塔网络，生成多尺度特征
3. **RPN（Region Proposal Network）**：区域提议网络，生成候选框
4. **ROI Head（Fast R-CNN Head）**：分类和回归头，对候选区域进行精细分类和定位

---

## 整体架构

```
输入图像 (3, H, W)
    ↓
Backbone (ResNet50) → 多个尺度的特征图
    ↓
FPN → {P2, P3, P4, P5, P6} 多尺度特征金字塔
    ↓
RPN → 生成候选区域（Region Proposals）
    ↓
ROI Pooling → 固定尺寸特征 (7×7)
    ↓
ROI Head → 分类 + 边界框回归
    ↓
输出：类别概率 + 精确边界框坐标
```

---

## 核心组件详解

### 1. Backbone: ResNet50

**作用**：从输入图像中提取特征

**结构**：
- Conv1: 7×7 卷积，stride=2 → 下采样 2×
- MaxPool: 3×3，stride=2 → 下采样 2×
- ResBlock1: 3 个残差块
- ResBlock2: 4 个残差块
- ResBlock3: 6 个残差块
- ResBlock4: 3 个残差块

**特征图尺寸**：
- C1: 原始输入
- C2: 下采样 4× (来自 ResBlock1)
- C3: 下采样 8× (来自 ResBlock2)
- C4: 下采样 16× (来自 ResBlock3)
- C5: 下采样 32× (来自 ResBlock4)

### 2. FPN (Feature Pyramid Network)

**作用**：构建多尺度特征金字塔，融合不同层级的语义信息和空间细节

**结构**：
- **自顶向下路径（Top-down）**：从高语义层到低语义层
- **横向连接（Lateral connections）**：融合不同层级的特征

**输出特征层**：
- P2: 高分辨率，强空间细节，适合小目标
- P3: 中等分辨率
- P4: 中等分辨率
- P5: 低分辨率，强语义信息，适合大目标
- P6: 从 P5 下采样得到，用于更大的目标

### 3. RPN (Region Proposal Network)

**作用**：在特征图上滑动窗口，预测每个位置是否包含目标，并生成候选框

**关键概念**：
- **Anchor（锚点）**：在每个特征图位置上设置多个预定义的框
  - 常见设置：3 个尺度（0.5×, 1×, 2×） × 3 个长宽比（0.5, 1, 2） = 9 个 anchor
- **分类分支**：判断 anchor 是前景还是背景
- **回归分支**：预测 anchor 到真实框的偏移量

**输出**：
- 前景/背景分数
- 边界框回归偏移量

### 4. ROI Head (Fast R-CNN Head)

**作用**：对 RPN 生成的候选区域进行精细分类和边界框回归

**结构**：
- **ROI Pooling/ROI Align**：将不同大小的候选区域统一到固定尺寸（如 7×7）
- **分类分支**：预测目标类别（背景 + N 个类别）
- **回归分支**：精细调整边界框位置

## 详细示例：RSNA肺炎检测

### 假设输入图像规格
- **输入图像尺寸**：1024 × 1024 像素
- **通道数**：3（RGB，虽然医学图像是灰度，但通过复制到3通道）
- **类别数**：2（背景 + 肺炎）

### 输入层
```
Input Image
形状: (1, 3, 1024, 1024)  # batch_size=1
数据类型: float32, 值域 [0, 1]
```

---

### 阶段 1: Backbone (ResNet50)

#### Conv1 层
```
输入: (1, 3, 1024, 1024)
卷积核: 7×7, 64 filters, stride=2, padding=3
输出: (1, 64, 512, 512)
参数量: 3 × 7 × 7 × 64 + 64 = 9,472
```

#### MaxPool 层
```
输入: (1, 64, 512, 512)
池化: 3×3, stride=2, padding=1
输出: (1, 64, 256, 256)
```

#### ResBlock1 (C2)
```
包含3个残差块，每个残差块包含：
- 1×1 卷积（降维）
- 3×3 卷积（主要特征提取）
- 1×1 卷积（升维）

最终输出: (1, 256, 256, 256)
下采样倍数: 4× (相对于输入)
```

#### ResBlock2 (C3)
```
包含4个残差块
第一个残差块进行下采样（stride=2）

输出: (1, 512, 128, 128)
下采样倍数: 8×
```

#### ResBlock3 (C4)
```
包含6个残差块
第一个残差块进行下采样（stride=2）

输出: (1, 1024, 64, 64)
下采样倍数: 16×
```

#### ResBlock4 (C5)
```
包含3个残差块
第一个残差块进行下采样（stride=2）

输出: (1, 2048, 32, 32)
下采样倍数: 32×
```

**Backbone 输出总结**：
```
C2: (1, 256, 256, 256)   # 下采样 4×
C3: (1, 512, 128, 128)   # 下采样 8×
C4: (1, 1024, 64, 64)    # 下采样 16×
C5: (1, 2048, 32, 32)    # 下采样 32×
```

---

### 阶段 2: FPN (Feature Pyramid Network)

FPN 使用 C2, C3, C4, C5 作为输入，生成 P2, P3, P4, P5, P6。

#### FPN 自顶向下路径

**P5 生成**（从 C5）
```
输入: C5 = (1, 2048, 32, 32)
1×1 卷积: 2048 → 256
输出 P5: (1, 256, 32, 32)
```

**P4 生成**（融合 C4 和上采样的 P5）
```
输入 C4: (1, 1024, 64, 64)
C4 → 1×1 卷积 → (1, 256, 64, 64)
P5 上采样 2× → (1, 256, 64, 64)
相加融合 → P4: (1, 256, 64, 64)
```

**P3 生成**（融合 C3 和上采样的 P4）
```
输入 C3: (1, 512, 128, 128)
C3 → 1×1 卷积 → (1, 256, 128, 128)
P4 上采样 2× → (1, 256, 128, 128)
相加融合 → P3: (1, 256, 128, 128)
```

**P2 生成**（融合 C2 和上采样的 P3）
```
输入 C2: (1, 256, 256, 256)
C2 → 1×1 卷积 → (1, 256, 256, 256)
P3 上采样 2× → (1, 256, 256, 256)
相加融合 → P2: (1, 256, 256, 256)
```

**P6 生成**（从 P5 下采样）
```
输入: P5 = (1, 256, 32, 32)
3×3 卷积，stride=2
输出 P6: (1, 256, 16, 16)
```

**所有特征层应用 3×3 卷积**（用于减少混叠效应）
```
每个 P_i 都经过 3×3 卷积，通道数保持 256
```

**FPN 输出总结**：
```
P2: (1, 256, 256, 256)   # 对应原图 4× 下采样，适合小目标
P3: (1, 256, 128, 128)   # 对应原图 8× 下采样
P4: (1, 256, 64, 64)     # 对应原图 16× 下采样
P5: (1, 256, 32, 32)     # 对应原图 32× 下采样
P6: (1, 256, 16, 16)     # 对应原图 64× 下采样，适合大目标
```

---

### 阶段 3: RPN (Region Proposal Network)

RPN 在每个 FPN 层（P2-P6）上独立运行。以 P4 层为例：

#### RPN 共享卷积
```
输入: P4 = (1, 256, 64, 64)
3×3 卷积，256 输出通道
输出: (1, 256, 64, 64)
```

#### Anchor 生成
假设每个位置生成 3 个尺度 × 3 个长宽比 = 9 个 anchor：

```
特征图大小: 64 × 64
总 anchor 数: 64 × 64 × 9 = 36,864 个 anchor
```

每个 anchor 的尺寸（以 P4 为例，对应原图 16× 下采样）：
- 尺度：32, 64, 128 像素（在原始图像上）
- 长宽比：0.5:1, 1:1, 2:1

#### RPN 分类分支（Objectness Score）
```
输入: (1, 256, 64, 64)
1×1 卷积，18 输出通道 (9 anchors × 2 classes: 前景/背景)
输出: (1, 18, 64, 64)
重塑: (1, 2, 9, 64, 64) → (1, 2, 36,864)
```
- 输出表示每个 anchor 是前景还是背景的概率

#### RPN 回归分支（Bounding Box Regression）
```
输入: (1, 256, 64, 64)
1×1 卷积，36 输出通道 (9 anchors × 4 coords: dx, dy, dw, dh)
输出: (1, 36, 64, 64)
重塑: (1, 4, 9, 64, 64) → (1, 4, 36,864)
```
- 输出表示每个 anchor 到真实框的偏移量

#### RPN 后处理
1. **应用偏移量**：将 anchor + 偏移量 → 候选框
2. **NMS（非极大值抑制）**：去除重叠的候选框
3. **选择 top-K**：选择得分最高的 N 个候选框（如 top-1000）

**所有 FPN 层的 RPN 输出汇总**：
```
P2 层: ~65,536 anchors → 经过 NMS 后约 200 个候选框
P3 层: ~16,384 anchors → 经过 NMS 后约 200 个候选框
P4 层: ~4,096 anchors → 经过 NMS 后约 200 个候选框
P5 层: ~1,024 anchors → 经过 NMS 后约 200 个候选框
P6 层: ~256 anchors → 经过 NMS 后约 200 个候选框

总候选框数（合并后）: ~1000-2000 个（经过 NMS 去重）
```

---

### 阶段 4: ROI Head (Fast R-CNN Head)

#### ROI Pooling / ROI Align

对每个候选框，从对应的 FPN 层提取特征：

```
输入候选框: N 个候选框（如 1000 个）
候选框坐标: (x1, y1, x2, y2) 格式，相对于原图

为每个候选框：
1. 根据候选框尺寸，选择对应的 FPN 层（小框→P2，大框→P5）
2. 将候选框映射到对应 FPN 层的坐标
3. ROI Align: 将候选区域池化到固定尺寸 7×7

输出: (N, 256, 7, 7)  # N 是候选框数量，如 1000
```

**ROI Align 详细过程**（以单个候选框为例）：
```
输入候选框在原图坐标: (x1=512, y1=512, x2=640, y2=640)  # 128×128 像素
选择 FPN 层: P4 (16× 下采样)
映射到 P4: (x1=32, y1=32, x2=40, y2=40)
ROI Align 到 7×7: 使用双线性插值，输出 (256, 7, 7)
```

#### ROI Head 分类分支

```
输入: (N, 256, 7, 7)
展平: (N, 256 × 7 × 7) = (N, 12,544)

全连接层 1:
输入: (N, 12,544)
权重: (12,544, 1024)
输出: (N, 1024)
激活: ReLU

全连接层 2 (分类):
输入: (N, 1024)
权重: (1024, num_classes)  # num_classes = 2 (背景 + 肺炎)
输出: (N, 2)
```
- 输出：每个候选框的类别概率分布

#### ROI Head 回归分支

```
输入: (N, 256, 7, 7)
展平: (N, 12,544)

全连接层 1（共享）: 同上
输出: (N, 1024)

全连接层 2 (回归):
输入: (N, 1024)
权重: (1024, 4 × num_classes)  # 每个类别4个坐标偏移
输出: (N, 8)  # 对于2类，实际上是 (N, 4)（只回归前景类）
```
- 输出：每个候选框的边界框精细调整偏移量

---

### 最终输出

```
分类输出: (N, 2)
- 每个候选框的类别概率 [背景概率, 肺炎概率]

回归输出: (N, 4)
- 每个候选框的边界框偏移量 [Δx, Δy, Δw, Δh]

最终检测结果（后处理）:
1. 应用回归偏移量到候选框
2. 应用 softmax 得到类别概率
3. 过滤低概率的框（阈值如 0.5）
4. NMS 去除重叠框
5. 输出最终的检测框: (M, 4) + 类别标签 + 置信度
```

## 前向传播流程

### 完整流程示例（批大小为1）

```
步骤 1: 输入
Input: (1, 3, 1024, 1024)

步骤 2: Backbone
C2: (1, 256, 256, 256)
C3: (1, 512, 128, 128)
C4: (1, 1024, 64, 64)
C5: (1, 2048, 32, 32)

步骤 3: FPN
P2: (1, 256, 256, 256)
P3: (1, 256, 128, 128)
P4: (1, 256, 64, 64)
P5: (1, 256, 32, 32)
P6: (1, 256, 16, 16)

步骤 4: RPN (以 P4 为例)
共享特征: (1, 256, 64, 64)
分类输出: (1, 18, 64, 64) → 重塑为 (1, 2, 36,864)
回归输出: (1, 36, 64, 64) → 重塑为 (1, 4, 36,864)
候选框: ~1000 个 (经过 NMS)

步骤 5: ROI Head
ROI 特征: (1000, 256, 7, 7)
展平: (1000, 12,544)
分类: (1000, 1024) → (1000, 2)
回归: (1000, 1024) → (1000, 4)

步骤 6: 后处理
最终检测框: M 个 (M ≤ 1000，经过置信度阈值和 NMS)
```

## 损失函数

Faster R-CNN 的总损失包括四个部分：

### 1. RPN 分类损失（Objectness Loss）
```
L_rpn_cls = CrossEntropyLoss(前景/背景预测, 真实标签)
```

### 2. RPN 回归损失（Bounding Box Loss）
```
L_rpn_reg = SmoothL1Loss(预测偏移量, 真实偏移量)
只对正样本（前景 anchor）计算
```

### 3. ROI Head 分类损失
```
L_cls = CrossEntropyLoss(类别预测, 真实类别)
```

### 4. ROI Head 回归损失
```
L_reg = SmoothL1Loss(边界框预测, 真实边界框)
只对正样本计算
```

### 总损失
```
L_total = L_rpn_cls + L_rpn_reg + L_cls + L_reg
```

## 参数量估算

以 ResNet50-FPN Faster R-CNN 为例：

1. **ResNet50 Backbone**: ~25M 参数
2. **FPN**: ~1M 参数
3. **RPN**: ~1M 参数
4. **ROI Head**: ~10M 参数

**总计**: ~37M 可训练参数

---

## 关键设计优势

1. **多尺度特征**：FPN 提供了不同尺度的特征，能够检测不同大小的目标
2. **两阶段设计**：RPN 生成候选框，ROI Head 精细分类和定位，分工明确
3. **端到端训练**：所有组件可以联合优化
4. **高效**：相比传统的选择性搜索，RPN 速度快得多

## 在 RSNA 肺炎检测中的应用

在您的项目中：
- **输入**：1024×1024 的 DICOM 图像（转换为 3 通道）
- **任务**：检测肺炎区域（bounding box）
- **类别**：2 类（背景 + 肺炎）
- **输出**：每个检测到的肺炎区域的坐标和置信度

模型通过学习大量标注的肺炎图像，能够自动识别和定位胸部 X 光片中的肺炎区域。
